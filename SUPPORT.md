# Support

Use the fastest support path for your situation.

| Need | Where |
|---|---|
| Bug report | GitHub Issues with the bug template |
| Feature idea | GitHub Issues with the feature template |
| Design discussion | GitHub Discussions |
| Security report | Follow `SECURITY.md` |
| Usage help | Discussions or examples in `examples/` |

Before opening an issue, please include:

- OMem version
- Python version
- Backend used
- Minimal reproduction code
- Expected and actual behavior

For agent integration issues, include the integration name, configuration snippet, and the exact tool call or command that failed.
